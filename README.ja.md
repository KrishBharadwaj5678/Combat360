# 🪖 コンバット360

**コンバット360** は、**AR.js** を使用して追跡画像上に3Dの `戦闘車両` を重ねて表示し、ブラウザ上でそのまま拡張現実を実現する没入型Web体験です！

![コンバット360](https://github.com/KrishBharadwaj5678/Combat360/raw/main/Combat360.png)

## 🚀 特徴

| **機能**             | **説明**                  |
| ------------------ | ----------------------- |
| 📸 **拡張現実**        | 追跡可能な画像上に3Dモデルを表示       |
| 📐 **モデル探索**       | ARで詳細な3Dモデルを探索          |
| 🛠️ **簡単セットアップ**   | 特別なハードウェア不要で素早くセットアップ可能 |
| 📱 **クロスプラットフォーム** | デスクトップとモバイルの両方で動作       |

---

## 🧑‍💻 使用技術

| **技術**         | **説明**                   |
| -------------- | ------------------------ |
| 🕹️ **エーアール・ジェイエス**  | 拡張現実のトラッキングとレンダリング       |
| 🌐 **エーフレーム** | Web上で3D体験を構築するためのフレームワーク |
| 🖥️ **エイチティーエムエル**   | Webページの構造とレイアウト          |
| 🎨 **シーエスエス**     | Webページのスタイリングとデザイン       |

## 🛠️ インストール

### 1️⃣ このリポジトリをクローンします：

```bash
git clone https://github.com/KrishBharadwaj5678/Combat360.git
```

### 2️⃣ プロジェクトディレクトリへ移動します：

```bash
cd Combat360
```

### 3️⃣ `index.html` をブラウザで開くか、ローカルサーバーで実行します。

---

## 💡 使用方法

1. リポジトリ内の *images* フォルダから **ARターゲット画像** をダウンロードします。
2. ブラウザでページを開きます。
3. デバイスのカメラを画像に向けると、3Dモデルが表示されます。
