# Combat 360 🪖

**Combat 360** is an immersive web experience that uses **AR.js** to overlay 3D models onto tracked images, bringing augmented reality to life right in your browser! 🌐

---

## Features 🚀

| **Feature**                         | **Description**                              |
| ----------------------------------- | -------------------------------------------- | 
| 📸 **Augmented Reality**             | Display 3D models on real-world images       |
| ☢️ **Interactive Combat Scenarios**  | Interact with models in real-time            |
| 🛠️ **Easy Setup**                  | Quick setup, no special hardware needed      |
| 📱 **Cross-Platform**             | Works on desktop and mobile                  |

---

## Installation 🛠️

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/combat-360.git
   ```
2. Navigate to the project directory:

   ```bash
   cd Combat360
   ```
3. Open `index.html` in your browser or run it on a local server.

---

## Usage 📸

1. **Download all the trackable images**: Get the images from the *images* folder from this GitHub repo. 
2. Load the page in your browser. 
3. Point your device's camera at the image, and watch the 3D model appear!
