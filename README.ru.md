# 🪖 Комбат 360

**Комбат 360** — это захватывающий веб-проект, использующий **AR.js** для наложения 3D-моделей `боевой техники` на отслеживаемые изображения, оживляя дополненную реальность прямо в вашем браузере!

![Комбат360](https://github.com/KrishBharadwaj5678/Combat360/raw/main/Combat360.png)

## 🚀 Возможности

| **Функция**                   | **Описание**                                         |
| ----------------------------- | ---------------------------------------------------- |
| 📸 **Дополненная реальность** | Отображение 3D-моделей на отслеживаемых изображениях |
| 📐 **Изучение моделей**       | Детальное исследование 3D-моделей в AR               |
| 🛠️ **Простая настройка**     | Быстрый запуск без специального оборудования         |
| 📱 **Кроссплатформенность**   | Работает на компьютерах и мобильных устройствах      |

---

## 🧑‍💻 Технологии

| **Технология** | **Описание**                               |
| -------------- | ------------------------------------------ |
| 🕹️ **AR.js**  | Трекинг и рендеринг дополненной реальности |
| 🌐 **A-Frame** | Фреймворк для создания 3D-веб-опыта        |
| 🖥️ **HTML**   | Структура и разметка веб-страниц           |
| 🎨 **CSS**     | Стилизация и оформление веб-страниц        |

## 🛠️ Установка

### 1️⃣ Клонируйте репозиторий:

```bash
git clone https://github.com/KrishBharadwaj5678/Combat360.git
```

### 2️⃣ Перейдите в папку проекта:

```bash
cd Combat360
```

### 3️⃣ Откройте `index.html` в браузере или запустите локальный сервер.

---

## 💡 Использование

1. Скачайте **AR-изображения-таргеты** из папки *images* репозитория.
2. Откройте страницу в браузере.
3. Наведите камеру устройства на изображение, и появится 3D-модель.
