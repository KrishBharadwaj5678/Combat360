# 🪖 Combate 360

**Combate 360** é uma experiência web imersiva que utiliza **AR.js** para sobrepor `Veículos de Combate` 3D em imagens rastreadas, trazendo a realidade aumentada à vida diretamente no seu navegador!

![Combate360](https://github.com/KrishBharadwaj5678/Combat360/raw/main/Combat360.png)

## 🚀 Recursos

| **Recurso**                  | **Descrição**                                             |
| ---------------------------- | --------------------------------------------------------- |
| 📸 **Realidade Aumentada**   | Exibe modelos 3D em imagens rastreáveis                   |
| 📐 **Exploração de Modelos** | Explore modelos 3D detalhados em AR                       |
| 🛠️ **Configuração Fácil**   | Configuração rápida, sem necessidade de hardware especial |
| 📱 **Multiplataforma**       | Funciona em desktop e dispositivos móveis                 |

---

## 🧑‍💻 Tecnologias

| **Tecnologia** | **Descrição**                                      |
| -------------- | -------------------------------------------------- |
| 🕹️ **AR.js**  | Rastreamento e renderização de realidade aumentada |
| 🌐 **A-Frame** | Framework para construir experiências 3D na web    |
| 🖥️ **HTML**   | Estrutura e layout das páginas web                 |
| 🎨 **CSS**     | Estilização e design das páginas web               |

## 🛠️ Instalação

### 1️⃣ Clone este repositório:

```bash
git clone https://github.com/KrishBharadwaj5678/Combat360.git
```

### 2️⃣ Navegue até o diretório do projeto:

```bash
cd Combat360
```

### 3️⃣ Abra o `index.html` no navegador ou execute-o em um servidor local.

---

## 💡 Uso

1. Baixe as **imagens-alvo AR** da pasta *images* do repositório.
2. Abra a página no navegador.
3. Aponte a câmera do seu dispositivo para a imagem e veja o modelo 3D aparecer.
